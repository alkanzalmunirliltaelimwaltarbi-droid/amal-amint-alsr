# نظام أمانة السر — الإصدار النهائي المطور

## تشغيل سريع
1. أنشئ Repository جديداً على GitHub.
2. ارفع **كل محتويات هذا المجلد** إلى الفرع `main`.
3. من GitHub افتح: Settings → Pages.
4. اختر: Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. افتح رابط GitHub Pages من Chrome على أندرويد.
7. اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## مكونات الإصدار
- `index.html`: النظام الأساسي الأصلي المقدم.
- `manifest.json`: تعريف تطبيق PWA.
- `sw.js`: التخزين المؤقت والعمل دون اتصال.
- `icon-192.png` و`icon-512.png`: أيقونات التطبيق.

## ملاحظة مهمة
البيانات التي يعتمد عليها النظام الأصلي محفوظة محلياً في المتصفح وفق تصميمه الحالي. يوصى باستخدام وظيفة النسخ الاحتياطي الموجودة في النظام بصورة دورية، خصوصاً قبل تغيير الهاتف أو المتصفح.
