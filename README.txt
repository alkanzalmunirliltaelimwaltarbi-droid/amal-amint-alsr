# برنامج حساب ساعات المدرسات — HTML/Android

الملف الرئيسي: `index.html`

## التشغيل
- افتحي `index.html` مباشرة في هاتف أندرويد أو الكمبيوتر.
- يعمل دون خادم ودون قاعدة بيانات خارجية، ويحفظ البيانات في LocalStorage على الجهاز.
- يمكن تغليفه لاحقًا كتطبيق Android (WebView/PWA) مجانًا.

## المزايا
- واجهة عربية RTL وتبويبات.
- إدارة المدرسات: إضافة/تعديل/حذف.
- داخل الملاك وخارج الملاك.
- أجرة الساعة مرتبطة بالشهادة مع إمكانية التعديل.
- تسجيل أسبوعي.
- سجل غياب وخصم.
- حساب الساعات المستحقة.
- ضريبة دخل كنسبة قابلة للتعديل.
- تقارير شهرية.
- طباعة PDF عبر نافذة الطباعة.
- تصدير Excel بصيغة XLS متوافقة مع Excel.
- شعار النسر المرفق مضمّن داخل التطبيق.
- اسم أمينة السر ومديرة الثانوية يظهران أسفل الكشف مباشرة.
- العام الدراسي قابل للتعديل.
- نسخ احتياطي واستعادة JSON.
- عبارة المصمم موجودة في واجهة البرنامج فقط ومخفية عن الطباعة والتصدير.

## ملاحظة
نسبة الضريبة وأجور الساعات الافتراضية إعدادات قابلة للتغيير وفق القرار المالي المعتمد لدى الجهة التعليمية.
